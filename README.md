# Frictionless Skeuomorphisum

Website for Vidyasagar Ayurvedic Chikitsalaya Trust.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

Static site assets are in `public/`. Doctor biodata and resumes in that folder
are publicly accessible. No hosting or deployment configuration is included.
